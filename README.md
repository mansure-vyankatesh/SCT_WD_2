# Chrono — Stopwatch Web Application

A responsive stopwatch built with HTML, CSS, and vanilla JavaScript for **SkillCraft Technology Web Development Internship — Task 02**.

## Features
- Start, pause, and resume the stopwatch.
- Reset elapsed time and lap history.
- Record lap durations and total elapsed time.
- Highlights the fastest and slowest lap.
- Responsive layout for desktop, tablet, and mobile.
- Keyboard-accessible buttons and reduced-motion support.
- No framework or build step required.

## Run locally
1. Download or extract the project.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `SCT_WD_2`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Your website URL will be:
   `https://YOUR-USERNAME.github.io/SCT_WD_2/`

## Project files
- `index.html` — page structure and controls.
- `style.css` — responsive styling and visual design.
- `script.js` — stopwatch timing and lap functionality.
